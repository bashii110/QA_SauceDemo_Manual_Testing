# SauceDemo Manual QA Testing Project

## 📌 Project Overview

This project demonstrates a complete **Manual Software Quality Assurance (SQA) testing workflow** performed on the SauceDemo e-commerce web application.

The project was created to practice and demonstrate real-world QA activities including test planning, test case design, functional testing, negative testing, exploratory testing, test execution, defect management, test reporting, and test evidence documentation.

---

## 🌐 Application Under Test

**Application:** SauceDemo
**Application Type:** E-commerce Web Application
**Testing Approach:** Manual Testing

The application provides common e-commerce functionality such as:

* User authentication
* Product browsing
* Product sorting
* Product details
* Shopping cart
* Checkout
* Order completion
* Navigation
* Logout

---

## 🎯 Testing Objectives

The main objectives of this project were to:

* Verify core application functionality.
* Validate positive and negative user scenarios.
* Verify form validation and error handling.
* Check product sorting and product information.
* Verify shopping cart operations.
* Validate the checkout workflow.
* Verify navigation and logout functionality.
* Perform exploratory testing to identify unexpected behavior.
* Document test results professionally.
* Maintain structured QA documentation.

## ▶️ Test Execution

Test cases were executed manually by following the documented test steps and comparing the observed behavior against the expected results.

The execution process included:

1. Preparing the test environment.
2. Opening the SauceDemo application.
3. Executing test cases individually.
4. Recording actual results.
5. Comparing actual results with expected results.
6. Assigning PASS/FAIL status.
7. Recording observations.
8. Reviewing unexpected behavior.
9. Preparing the execution report.

## 🐞 Defect Management

Potential issues were reviewed during functional and exploratory testing.

A behavior was only considered a defect when it could be reproduced and was determined to differ from the expected application behavior.

No confirmed reproducible defects were identified within the tested scope.
